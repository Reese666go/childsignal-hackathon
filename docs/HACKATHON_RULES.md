## ChildSignal 的赛道选择

主赛道：**Professional Agents**。

理由：ChildSignal 帮助幼儿教师处理长期、重复且需要专业判断的观察工作，使教师更有效地完成原本的工作。学校也符合 Good Neighbor 场景，但一个清晰赛道更便于评委理解。

## 硬性要求

- 在提交期内新建项目。
- 使用 Strands Agents SDK，完成真实用户的端到端工作，而不是只聊天。
- 提供公开 GitHub、GitLab 或 Bitbucket 仓库。
- 仓库包含全部源码、资源和运行说明。
- 使用 MIT 或 Apache 开源许可证，并让许可证在仓库首页可见。
- 包含 README 和架构图。
- 提交最长 5 分钟的公开 YouTube 或 Vimeo 视频。
- 视频展示运行中的项目，并说明问题、用户与价值。
- 所有提交材料使用英文，或提供英文翻译。

可选但加分：在线 Demo、AgentCore 部署、builder.aws 构建文章。

## 同权重评分项

1. Technical Implementation
2. Design
3. Potential Impact
4. Creativity & Originality
5. Presentation

## 对当前开发的直接影响

- 代码必须真实调用 Strands `Agent`，不能只做静态界面。
- Demo 必须跑通端到端闭环。
- AgentCore 留作部署阶段，不阻塞本地 MVP。
- README、许可证和架构图从第一天纳入仓库。
